# Owen Hektner — Portfolio

Personal portfolio site built with vanilla HTML/CSS/JS. Live at [ohek54.github.io/Portfolio](https://ohek54.github.io/Portfolio).

## Stack

- Pure HTML, CSS, JavaScript — no frameworks or build step
- Hosted on GitHub Pages
- Fonts via Google Fonts (Inter, Inter Tight, JetBrains Mono)

## Structure

```
index.html        # Main site
media/
  portrait.jpg
  healthcare-1.png / healthcare-2.png
  liquor-1.png / liquor-2.png / liquor-3.png
  nba-1.png / nba-2.png
  Owen_Hektner_Resume.pdf
```

## Updating

Edit `index.html` or swap files in `media/`, then:

```bash
git add .
git commit -m "your message"
git push
```

GitHub Pages deploys automatically within ~60 seconds.
